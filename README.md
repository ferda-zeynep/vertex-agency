Vertex Agency - Modern Community & Design Solutions
A pixel-perfect, high-performance digital agency landing page engineered to showcase advanced frontend capabilities. Originally implemented from a precise Figma blueprint, this project focuses on robust responsive workflows, clean asset management, and semantic UI architecture.

🚀 Live Demo
You can view the live deployment here: https://nexcent-ten-lac.vercel.app

🛠️ Tech Stack & Architecture
Framework / Library: React 18

Build Tool / Bundler: Vite

Styling: Tailwind CSS (Utility-first framework)

Icons: React Icons & Lucide React

Carousel Component: React Slick & Slick Carousel

Language: JavaScript (ES6+)

📁 Key Features & Engineering Highlights
Figma-to-Code Precision: Translated directly from production-grade UI design specifications with meticulous attention to spacing, padding, font weights, and layout symmetry.

Fluid Responsive Layouts: Re-architected rigid sections into flexible Grid and Flexbox layouts, ensuring fluid asset scaling across mobile, tablet, and desktop viewports.

Interactive UI Animations: Implemented multi-layered Tailwind hover groups (group-hover) to provide tactile, high-end interactive micro-animations for buttons and cards.

Modern Asset Workflow: Tailored use of inline graphics and organized SVG vectors to ensure crisp resolution at any screen density while maintaining lightning-fast rendering speeds.

💻 Local Development
To spin up this repository on your local machine, run the following commands in your terminal:

Clone the repository:
git clone https://github.com/ferda-zeynep/vertex-agency.git

Navigate into the project directory:
cd vertex-agency

Install project dependencies:
npm install

Launch the local development server:
npm run dev

Open http://localhost:5173 in your browser to view the application.
